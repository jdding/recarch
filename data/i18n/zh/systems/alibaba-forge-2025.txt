era_reason|研究生成式召回模型所写的 semantic ID 该怎么构造；召回器是生成 3 层 semantic ID 的 LLM 式解码器，属于生成式范式。
tldr|淘宝的 FORGE 系统比较了生成式召回的 semantic ID 构造方法；把基础 SID 方案换成调优后的方案，在猜你喜欢的 7 天 A/B 中成交笔数 +0.35%。
summary|FORGE 是围绕一个问题的基准和数据集：生成式召回 GR 模型该如何构造 semantic ID，即 SID。SID 流水线分三步。特征提取：用预训练的多模态编码器和 QFormer 融合 item 的文本和图像特征，可选地加入基于 item 共现的对比损失。SID 编码：用 RQ-VAE 把融合后的特征量化成三个码字，对比的方案有随机分配、multiple VQ、OPQ 和 RQ-Kmeans。后处理：用基于 KNN 或基于随机的规则，限制共用同一个 SID 的 item 数量。Qwen2.5 这类 decoder-only LLM 或 T5 模型把用户历史读成 SID，再用 beam 数从 300 增加到 600 再到 1200 的动态 beam search 生成目标 SID。论文还提出两个不需要训练 GR 的 SID 质量指标，Embedding HitRate 和 Gini 系数，并发布了 AL-GR 数据集。调优后的方案先在淘宝首页做了线上测试，随后全量部署。
core_idea|用融合了多模态和共现信息的特征构造 semantic ID，再把 item 均匀地分散到各个码字上。

results_reported|离线，AL-GR 的 S3 阶段，Final 对比 base SID 方案：HR@20 从 4.33% 提高到 5.44%，HR@1000 从 27.24% 提高到 30.86%，相对提升分别为 +25.64% 和 +13.29%。在 Amazon 上，Final 的 HR@1000 为 13.04%，base 为 8.07%。同样的方案在淘宝搜索任务上也有提升。线上，在淘宝首页猜你喜欢板块做了 7 天 A/B，Final 对比 base：PVR +8.93%，HR +10.02%，成交笔数 +0.35%。摘要称这些 SID 构造策略此后已在淘宝全量部署。
