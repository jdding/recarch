era_reason|这是一个在点击类目标上训练的判别式 token 排序模型；改变发生在表示层，用离散的多模态语义编码替换候选侧的 item ID，而不是自回归地生成 item。
tldr|字节的 FLUID 把生产直播排序模型里的 item ID 去掉，换成多模态语义编码；A/B 下优质观看时长 +0.55%，冷启动直播间曝光 +2.05%。
summary|直播间只在开播期间才是候选，中位生命周期约 40 分钟，所以它的 item ID embedding 永远收敛不了。FLUID 分三部分把生产排序模型里候选侧的 item ID 去掉。第一，跨域多模态编码器由 SigLIP2-base 视觉模块和 Qwen3-Embedding-0.6B 单塔融合模块组成，输入是视觉 token 以及来自标题、OCR、ASR、简介、评论和标签的文本 token，在直播和短视频两类内容的 2 分钟切片上用 query 到 item 的对比损失训练，输出 128 维向量。第二，RQ-KMeans 把每个切片向量变成 4 层编码，每层 64 个聚类，称为 LUCID；直播间级别的 LUCID 来自同一场次各切片上逐层的多数投票。第三，这些编码作为独立的切片 token 和直播间 token 进入排序模型，也就是 Zenith++ 流水线中基于 token 的类 transformer 骨干，使用前缀 n-gram embedding 表，采用晚融合，而不是先与 ID 合并。切换靠分阶段预热完成：先在 item ID 旁加入切片 LUCID，再逐步去掉 item ID，最后加入用切片表初始化的直播间 LUCID，然后在没有 item ID 的情况下继续线上流式训练。
core_idea|去掉直播排序模型里候选侧的 item ID，用分阶段预热加入的离散多模态 LUCID 编码来承担它的角色。
