summary|TGR 是腾讯 PCG 的生成式推荐技术栈，由 TGR 团队的技术报告介绍。TGR-GenRank 即 CCFormer，是一个排序模型，包含统一特征 tokenization、按特征域分离的 cross attention、子空间 token 混合和层级序列压缩，仍然输出每个 item 的多任务分数，因此可以直接放进现有的级联。TGR-GenRec 有两种生成范式。BARGE 用 beam search 生成 Semantic ID 路径，并把它们作为 embedding query 用在召回通道中。HiGR 用规划器和基于前缀结构 Semantic ID 的 item 生成器生成整个 slate，并用 listwise 偏好优化做对齐。TGR-Reason 在离线运行大模型 Think 模型，把推理 token 写成 Semantic ID，用来提示在线解码器，请求时不需要做推理展开。

results_reported|CCFormer 在五个场景中做了两周 A/B，所有提升在 p < 0.05 下显著。在视频场景中，它取代了长期使用的 DLRM，CTR +3.57%，page view +3.86%，观看时长 +1.29%，独立观看用户 +2.61%；在广告排序场景中，它取代了 HSTU，广告收入 +1.71%。两者随后都已全量上线。它的训练速度比 HSTU 快 2.21x，GFLOPs 约为一半。BARGE 在 6% 流量上跑了两周，对比多阶段的原有系统：CTR +0.60%，点击用户数 +1.34%，总阅读时长 +1.70%，随后作为召回通道全量上线。离线 Hit@5 比 OneRec 高 10.2-16.9%。HiGR 在一个场景的 5% 流量上，平均观看时长 +1.22%，平均视频观看数 +1.73%；在另一个场景中 CTR +0.68%，广告收入 +0.56%。TGR-Reason 使冷启动新用户的 Hit@1 从 0.0451 提高到 0.2606，即 +477.8%，线上有效消费率 +1.75%，新用户曝光到转化率 +13.09%。
